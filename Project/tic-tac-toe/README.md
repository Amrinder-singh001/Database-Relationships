# Tic Tac Toe Game

This is a simple Tic Tac Toe game implemented using HTML, CSS, and JavaScript. The game allows two players to take turns marking spaces in a 3x3 grid. The first player to align three of their marks horizontally, vertically, or diagonally wins the game.

## Files Overview

- **index.html**: Contains the structure of the Tic Tac Toe game, including the game board and buttons for player interaction.
- **style.css**: Defines the styles for the game, including layout, colors, and visual appearance.
- **script.js**: Contains the JavaScript logic for handling player moves, checking win conditions, and updating the game state.

## How to Play

1. Open the `index.html` file in a web browser.
2. Players take turns clicking on the empty squares of the grid to place their marks (X or O).
3. The game checks for a winner after each move. If a player aligns three marks in a row, they win the game.
4. If all squares are filled and no player has won, the game ends in a draw.
5. Refresh the page to start a new game.

## Additional Information
